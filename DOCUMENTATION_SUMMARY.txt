🤖 EMPAT AI AGENTS DIJELASKAN
================================================================================

1. IRIS 📊 - Data Agent
   ├─ Capabilities: SQL, charts, analytics, reports
   ├─ Use for: Revenue, CAC/LTV, business metrics
   ├─ Output: dashboard, query_result
   ├─ PromptQL Programs: 3 (revenue, segmentation, churn)
   └─ Example: "@Iris show revenue vs target last 6 months"

2. ATLAS 🧠 - Knowledge Agent
   ├─ Capabilities: Search, context, timeline, org info
   ├─ Use for: Q&A about strategy, decisions, history
   ├─ Output: text
   ├─ PromptQL Programs: 3 (search, cross-reference, timeline)
   └─ Example: "@Atlas what's our product roadmap?"

3. NEXUS ⚙️ - Process Agent
   ├─ Capabilities: SOP creation, workflows, automation, docs
   ├─ Use for: Process documentation, onboarding
   ├─ Output: sop
   ├─ PromptQL Programs: 3 (template, incidents, automation)
   └─ Example: "@Nexus create onboarding SOP for engineers"

4. ECHO 💬 - Comms Agent
   ├─ Capabilities: Summarize, draft, emails, communications
   ├─ Use for: Summaries, drafts, updates
   ├─ Output: text
   ├─ PromptQL Programs: 3 (aggregation, decision, context)
   └─ Example: "@Echo summarize #engineering this week"

🔄 HOW ROUTING WORKS (Keyword Detection)
================================================================================

USER INPUT KEYWORDS → AGENT SELECTION:

"revenue", "sales", "metrics" → IRIS (Data Agent)
"sop", "process", "how-to"   → NEXUS (Process Agent)
"create", "build", "make"    → ECHO (Comms Agent)
"who", "what", "explain"     → ATLAS (Knowledge Agent)
(default / no match)         → ATLAS (fallback)

================================================================================
✨ KEY FEATURES OF THIS SYSTEM
================================================================================

1. SEMANTIC ROUTING
   - Automatic agent selection based on keywords
   - Falls back to Atlas if no match found

2. KNOWLEDGE INTEGRATION
   - All agents query knowledge brain for context
   - Semantic search via tags and categories
   - Cross-reference related documents

3. PROMPTQL EXECUTION
   - Deterministic SQL query execution
   - Real-time data retrieval
   - Reliable for critical queries

4. MULTIPLE OUTPUT FORMATS
   - Dashboard (charts & metrics)
   - Query Result (data tables)
   - SOP (step-by-step procedures)
   - Text (explanations, summaries)
   - Task (multi-agent breakdown)

5. MESSAGE PERSISTENCE
   - All interactions stored in Supabase
   - Full conversation history
   - Structured metadata for each response

6. REAL-TIME COLLABORATION
   - Multiple users in same workspace
   - Instant message delivery
   - Agent responses visible to all

JOURNEY 3: Strategy Clarification

├─ Response: text draft with key points, decisions, metrics
└─ Result: Manager gets draft update in seconds, ready to customize
